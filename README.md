# Capitão Gambiarra — Ficha de Herói

Projeto acadêmico desenvolvido com HTML e CSS para apresentar um personagem original em uma página inspirada em uma ficha de RPG.

## Sobre o personagem

Capitão Gambiarra é um herói inventor, conhecido por sua inteligência, criatividade e jeito atrapalhado.

Ele utiliza ferramentas e invenções improvisadas para resolver problemas e proteger as pessoas da cidade.

Sua principal habilidade é a Gambiarra Suprema, que permite criar soluções usando praticamente qualquer objeto disponível.

## Tecnologias utilizadas

- HTML: estrutura e conteúdo.
- CSS: cores, layout, barras de atributos e responsividade.
- Flexbox: organização do menu e de alguns elementos.
- CSS Grid: organização dos cards do inventário.
- Media Queries: adaptação para celular, tablet e computador.

## Seções da página

- Sobre o Herói.
- Atributos e Habilidades.
- Inventário e Conquistas.
- Contato com a Guilda.

## Decisões de UI/UX

### Hierarquia visual

O nome Capitão Gambiarra aparece em tamanho maior, enquanto os títulos das seções utilizam laranja para destacar as principais partes da página.

### Contraste e legibilidade

Os textos claros aparecem sobre fundos azul escuro e cinza, facilitando a leitura.

Os elementos importantes utilizam laranja e amarelo para criar destaque.

### Consistência

Os cards, botões, títulos e barras de atributos seguem o mesmo padrão de cores, bordas arredondadas e espaçamentos.

### Proximidade e agrupamento

Cada atributo apresenta seu nome, porcentagem e barra de progresso juntos.

Os itens do inventário também mantêm nome, raridade e descrição no mesmo card.

### Indicação de interação

Os links, botões e cards possuem efeitos de hover para mostrar quando podem ser clicados ou possuem algum tipo de interação.
